# 🦓 Fast Jira

### Jira의 복잡함을 줄이고 내 작업에 집중합니다.

프로젝트와 하위 작업을 한눈에 보고, 필요한 변경을 바로 처리하는 로컬 워크스페이스입니다.

## 주요 기능

| 찾기 | 확인하기 | 처리하기 |
| --- | --- | --- |
| 프로젝트와 하위 작업 탐색 | 목록과 상세를 나란히 보기 | 제목, 작업참여자, 상태, 우선순위 수정 |
| 내 작업과 작업 관계자 필터 | 본문, 첨부 이미지, 변경 기록 확인 | 여러 이슈를 선택해 일괄 변경 |
| 프로젝트와 필터를 저장하는 뷰 탭 | 상위 경로와 하위 작업 확인 | 댓글, 답글, @멘션 작성 |
| 즐겨찾기와 최근 본 이슈 | 선택한 프로젝트의 최근 활동 확인 | 결과 알림과 되돌리기 |
| 검색과 명령 팔레트 | Codex, Claude와 AI 대화 | 프로젝트 이슈와 하위 작업 생성 |

### 보던 작업을 이어서 확인합니다

- 저장된 목록을 먼저 보여주고 변경된 내용을 확인해 반영합니다.
- 필드를 수정할 때마다 전체 목록을 다시 불러오지 않습니다.
- 화면을 보고 있지 않을 때는 주기 조회를 멈춥니다.
- 좁은 화면에서도 목록과 상세를 이어서 탐색할 수 있습니다.

### 각자의 계정과 권한으로 사용합니다

각자의 Jira 계정으로 연결합니다. API 토큰은 로컬 서버에 보관하며 브라우저 저장소나 배포 파일에 넣지 않습니다. 별도 클라우드 서버나 ACLI 없이 동작합니다.

AI 대화에 보낸 내용은 선택한 AI 서비스로 전달됩니다. 로컬에서 실행된다는 이유로 모든 정보가 컴퓨터 안에서만 처리되는 것은 아닙니다. 회사의 AI 이용 기준에 맞게 사용해 주세요.

## AI에게 설치 맡기기

아래 문장을 **Codex 또는 Claude Code**에 전달해 주세요.

```text
https://github.com/hellojianijinworld/fast-jira 를 읽고 이 컴퓨터에 설치해줘.
README의 AI 설치 가이드를 따라 최신 정식 릴리스를 설치하고,
지금 사용하는 AI에 플러그인과 MCP를 등록한 뒤 앱을 열어줘.
기존 설정은 보존하고 Jira 토큰은 내가 앱에 직접 입력할게.
```

| 스킬 | 요청 예시 |
| --- | --- |
| **Setup** | "Fast Jira 설치하고 열어줘." |
| **Managing** | "실행 상태 확인해줘." "업데이트해줘." "종료해줘." |
| **Contribute** | "Fast Jira 개발 환경을 준비해줘." |

AI가 정식 릴리스의 실행용 ZIP을 받아 설치합니다. 일반 설치와 업데이트에는 Git이나 npm 빌드가 필요하지 않습니다.

- Node.js 24.22.2와 로컬 명령을 실행할 수 있는 Codex 또는 Claude Code가 필요합니다. 일반 ChatGPT, Claude 웹채팅만으로 설치하는 방식은 아닙니다.
- Jira 연결 정보는 앱에 직접 입력합니다. 토큰을 AI 대화에 붙여넣지 않습니다.
- 선택 도메인의 최초 설정에는 npm이 필요합니다. Windows 구현은 OpenSSL도 사용합니다.
- 도메인 설정에 필요한 승인은 OS 창에서 직접 진행합니다. 승인하지 않거나 연결에 실패하면 localhost로 사용합니다.

설치 절차는 [AI 설치 가이드](INSTALL.md), 개발 절차는 [기여 가이드](CONTRIBUTING.md)에 정리했습니다.

`v0.1.1`부터 Windows 도메인 자동 설정을 포함합니다. 기본 주소는 localhost이며, 선택 도메인은 설정 동의와 실제 연결 확인이 끝난 경우에 사용합니다. 지원과 검증 범위는 아래에서 확인할 수 있습니다.

## 처음 열었다면

1. 앱에서 Jira 사이트, Atlassian 이메일, API 토큰을 입력합니다. [토큰 발급](https://id.atlassian.com/manage-profile/security/api-tokens)은 본인이 진행합니다.
2. **프로젝트 선택**에서 현재 뷰에 표시할 프로젝트를 고릅니다.
3. 필터와 화면 표시는 필요할 때 설정합니다. 건너뛰고 시작한 뒤에도 바꿀 수 있습니다.

컴퓨터를 다시 켠 뒤에는 AI에게 "Fast Jira 실행해줘"라고 요청해 주세요. OS 자동 시작은 등록하지 않습니다.

## 업데이트와 의견 보내기

새 정식 릴리스가 있으면 업데이트 아이콘과 파비콘의 주황색 점으로 안내합니다. **메뉴 > 업데이트 확인**에서 변경 내용을 보고 직접 실행합니다. 앱과 이미 설치한 Fast Jira 플러그인을 함께 갱신하며 Jira 연결 설정은 보존합니다.

GitHub에 코드를 푸시하는 것만으로 기존 설치본이 바뀌지는 않습니다. 더 높은 버전의 정식 릴리스가 게시되어야 업데이트로 안내합니다.

의견은 앱의 **메뉴 > 의견 보내기** 또는 아래 링크로 남겨 주세요. GitHub에서 내용을 확인한 뒤 제출합니다.

- [버그 제보](https://github.com/hellojianijinworld/fast-jira/issues/new?template=bug.yml)
- [개선 및 기능 제안](https://github.com/hellojianijinworld/fast-jira/issues/new?template=feature.yml)
- [설치 및 사용 문의](https://github.com/hellojianijinworld/fast-jira/issues/new?template=question.yml)

토큰, 회사 이슈 본문, 대화, 원본 로그는 올리지 않습니다. 캡처를 첨부할 때도 민감한 정보는 가려 주세요.

## 지원 및 검증 범위

- Jira Cloud를 지원하며, 연결한 계정의 접근 권한을 따릅니다.
- Codex와 Claude Code 플러그인이 공통 로컬 웹 서버와 MCP 서버를 사용합니다.
- macOS는 공개 배포본으로 실제 설치와 도메인 접속을 확인했습니다.
- Windows는 CI의 실제 Windows 환경에서 도메인과 HTTPS 구성을 확인했습니다. 대화형 UAC, 사용자 인증서 승인, 브라우저와 앱 전체 설치는 별도 확인이 필요합니다.
- Linux용 실행 경로를 제공하지만 앱 전체 설치는 별도 확인이 필요합니다. 도메인 자동 설정은 제공하지 않습니다.
- 기본 접속은 localhost입니다. 도메인 지원 여부는 설치한 릴리스를 기준으로 확인합니다.
- MCP 수정은 확인 UI를 지원하는 클라이언트에서 사용자 승인 후 실행합니다.
- 댓글 좋아요와 이모지 반응은 지원하지 않습니다. 답글은 Jira의 공개 문서에 없는 동작에 의존합니다.

Jira와 Atlassian의 공식 제품이 아닙니다. [MIT 라이선스](LICENSE)로 배포합니다.
